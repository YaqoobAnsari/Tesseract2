# Paper — TSAS Revision Round 1

## Files

| File | Role | Edit? |
|---|---|---|
| `initial_submission.tex` | The initial submission (frozen reference) | **Never** |
| `main_revision_1.tex` | The working revision — all changes go here, colour-coded | Yes |
| `main_revision_1_clean.tex` | Non-coloured copy, regenerated by `make_clean.sh` | Never by hand |
| `revision_macros.tex` | Per-reviewer colour commands (caption-safe) | Rarely |
| `response_to_reviewers.tex` | Point-by-point response letter (reviews verbatim, colour-coded) | Yes |
| `table_of_changes.tex` | Summary of changes (input by the response letter) | Yes |
| `REVISION_CHECKLIST.md` | Full work plan: review actions, section plan, inconsistency fixes | Track status |
| `make_clean.sh` | Regenerates the clean copy from the coloured one | Run after edits |
| `bibliography.bib` | Shared bibliography | Yes |

## Colour code

- `\rone{...}` Reviewer 1 — blue
- `\rtwo{...}` Reviewer 2 — green
- `\rthree{...}` Reviewer 3 — purple
- `\rall{...}` Editor / multiple reviewers — vermilion
- `\rdel{...}` Deleted text (struck-out in coloured copy, absent in clean copy)

All macros are robust: they work in `\caption{}`, `\section{}`, table cells, and footnotes.

## Workflow

1. Make edits in `main_revision_1.tex`, wrapping every change in the requesting
   reviewer's colour macro (`REVISION_CHECKLIST.md` says which reviewer owns which edit).
2. Run `./make_clean.sh` to refresh `main_revision_1_clean.tex`.
3. Mirror each change in `response_to_reviewers.tex` (fill the `[p. XX]` markers last,
   after the manuscript is frozen) and keep `table_of_changes.tex` current.
4. Compile on a machine with LaTeX (none is installed here): both revision files,
   plus the response letter, must build cleanly before submission.

## Note on the base document

`initial_submission.tex` is the manuscript version present in this repository. If the
version submitted to the TSAS Author Center differs (e.g., contains the full Tables 1–5
and Figures 3/5/8 the reviews reference), place those sources here and re-run the setup:
the colour macros, response letter, and checklist carry over unchanged.
